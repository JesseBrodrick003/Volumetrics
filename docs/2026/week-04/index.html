"Last 4 games" adds up each team's four most recent games (bye weeks skipped), so the oldest game drops off each week. Shares there are totals over those games; a game a player missed counts as zero.

Targets, red-zone targets and receiving lines from nflverse play-by-play. Snap counts from Pro Football Reference via nflverse. Drops from FTN Data via nflverse (CC-BY-SA 4.0). Red zone means inside the opponent's 20. Takes are rule-based, from these numbers.
